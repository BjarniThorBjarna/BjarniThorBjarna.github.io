# BjarniThorBjarna.github.io
Personal website hosted with GitHub Pages

Visit https://bjarnithorbjarna.github.io/ for the app launcher.
The **My weather** icon opens `my-weather.html`, the uploaded weather app.
The **Backgammon** icon opens `backgammon.html`, a local 2-player game.
Weather updates require an internet connection.

To add another app, upload its HTML file to the `main` branch and add a link
inside `<nav class="apps">` in `index.html`. Changes publish automatically
through GitHub Pages.
